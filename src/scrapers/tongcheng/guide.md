# 同程旅行 使用指南

## 用途

同程旅行社会招聘（`mhr.ly.com/recruit/portal/`）的公开 JSON 接口。岗位带薪资范围（部分岗位为「0～0」表示未公开，已自动忽略），适合互联网社招岗位分析与投递清单。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| keyword | 否 | 搜索关键词（如 "Agent"、"产品"、"Java"）；为空时拉取全部社招岗位 |
| city | 否 | 城市名（如 "北京"）；接口不按地点过滤，由本地按工作地点匹配 |
| limit | 否 | 返回数量上限，默认 20，最大 100 |

## 调用示例

```
fetch_company_jobs(company="tongcheng", params='{"keyword":"Agent","limit":5}')
fetch_company_jobs(company="tongcheng", params='{"city":"北京","limit":10}')
```

## 返回字段

| 字段 | 说明 |
|------|------|
| title | 岗位名称 |
| url | 详情页链接（`#/socialDetail?id=...&type=4`） |
| company | 同程旅行 |
| location | 工作地点，多城市以逗号分隔（如 "北京,成都"） |
| salary | 薪资范围（如 "30000～45000"），未公开时为空 |
| summary | 薪资 / 地点 / 用工类型摘要 |
| job_type | 用工类型（如 "正式-正式"） |
| publish_time | 发布时间 |
| job_id | 岗位 ID |

## 数据口径

- 只覆盖社会招聘（`queryType=4`）。校园招聘、实习、外部推荐分别对应 queryType 3/5/6，本源未开放。
- 列表与详情请求均为 JSON，并需携带 `companyId: 0583d` 请求头。

## 错误处理

| 错误 | 原因 | 解决 |
|------|------|------|
| 同程旅行接口请求失败 | 网络异常或接口临时不可用 | 稍后重试 |
| 同程旅行列表接口返回错误 | 接口参数或服务端逻辑变化 | 检查 queryType 与分页参数 |
| 未找到相关岗位 | 关键词无匹配 | 更换关键词或留空拉取全量 |
| 未找到该岗位的列表快照 | 未经 search 直接取详情且详情为空 | 先调用 search |
