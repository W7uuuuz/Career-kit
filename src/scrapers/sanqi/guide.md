# 三七互娱 使用指南

## 用途

搜索三七互娱社会招聘岗位。数据来自 `zhaopin.37.com` 的公开网页接口，
无需登录；详情页为服务端渲染 HTML，包含职位描述与任职要求。不公开薪资。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| keyword | 否 | 搜索关键词，如 `"策划"`、`"Java"`；为空时拉取全量 |
| city | 否 | 城市名，如 `"广州"`、`"上海"`；服务端按工作地点筛选 |
| limit | 否 | 返回数量上限，默认 20，最大 100（接口每页 8 条） |

## 调用示例

```
fetch_company_jobs(company="sanqi", params='{"keyword":"策划","city":"广州","limit":10}')
```

## 返回字段

| 字段 | 说明 |
|------|------|
| title | 岗位名称 |
| url | 岗位详情链接 |
| company | 三七互娱 |
| location | 工作地点 |
| department | 岗位类型 |
| summary | 职位描述摘要 |
| job_id | 三七互娱岗位 id |
| job_type | 社会招聘 |
| source | sanqi |

`fetch_jd_detail` 返回 `description`、`requirements`、`location` 等字段。

## 注意事项

1. 当前只接入社会招聘（`c=society`）。校招页签仍指向旧的 Moka 门户，职位多为已停招状态，未接入。
2. 接口每页固定 8 条，按 `pageCount` 翻页，设有限流保护。
3. 数据来自公开页面，不绕过登录，不公开薪资。

## 错误处理

| 错误 | 原因 | 解决 |
|------|------|------|
| 三七互娱接口请求失败 | 网络波动或站点临时不可用 | 稍后重试 |
| 三七互娱接口返回格式异常 | 接口结构变化 | 检查站点是否改版 |
| 三七互娱详情解析失败 | 详情页模板变化 | 打开详情链接确认页面结构 |
