# {公司名} 使用指南

> 贡献新 scraper 时复制本模板到你的包目录并填写。
> 本文件是 LLM 运行时按需读取的使用教程（get_scraper_guide 工具），请认真填写。

## 用途

一两句话说明：这个源提供什么数据、适合什么分析场景。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| keyword | 是 | 搜索关键词 |
| limit | 否 | 返回数量上限 |

## 调用示例

```
fetch_company_jobs(company="{company_id}", params='{"keyword":"..."}')
```

## 返回字段

| 字段 | 说明 |
|------|------|
| title | 岗位名称 |
| url | 详情页链接 |
| summary | 摘要 |

## 注意事项

1. 登录要求 / 频率限制 / 数据特殊性等，写清楚

## 可选章节

以下章节按需添加（多数正式源都有）：

- **错误处理**：`| 错误 | 原因 | 解决 |` 三列表格，逐条给出可执行的解决办法
