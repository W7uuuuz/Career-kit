# GitHub 经验帖 使用指南

## 用途

搜索 GitHub 上的**秋招/春招经验帖**——offer 复盘（成功经验）与面试复盘（面经）。
这是「同背景成功经验」的最优来源之一：开源社区无登录墙、标题自述格式规整，
通过 Search API 直接抓取（无需浏览器）。
从中学到的东西包括：岗位方向、必备技能、路径抉择（先进小厂攒经历还是直接冲大厂）。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| keyword | 是 | 搜索关键词，如 `"AI Agent"`、`"后端"`；工具自动拼接「秋招/春招/面经/offer/实习」意图词与「双非/985/211」学历词 |
| education | 否 | 学历档位词，如 `"双非"`、`"985硕"`、`"二本"`——同时参与搜索与打标 |
| filter_company | 否 | 公司名称，如 `"字节"`——拼接到搜索词 |
| order | 否 | `"created"`（默认，最新）或 `"best"`（综合相关） |
| page | 否 | 页码，默认 1 |
| limit | 否 | 返回上限，默认 20（最大 30） |

## 调用示例

```
fetch_company_jobs(company="github", params='{"keyword": "AI Agent", "education": "双非", "filter_company": "字节", "limit": 10}')
```

## 返回字段

| 字段 | 说明 |
|------|------|
| title | 经验帖标题（通常含公司/学历/结果） |
| url | issue 详情页链接（可传给 fetch_jd_detail） |
| date | issue 创建日期 |
| snippet | 正文摘要（前 300 字） |
| education_tag | 归一化学历标签（「双非本」「211硕」等） |
| reactions | 帖子点赞数——高赞通常质量更高 |
| source | `github` |

## 搜索词参考

- 学历词（免费提取）常用写法：985、211、双非、普本、二本、三本、一本
- 方向词示例：后端、前端、算法、AI Agent、数据分析

## 错误处理

| 错误 | 原因 | 解决 |
|------|------|------|
| `GitHub 搜索限流` | 未认证身份超限（10 次/分钟） | 设置 `GITHUB_TOKEN` 环境变量（可达 30 次/分钟） |
| `搜索词过于复杂` | keyword 太长或含特殊字符 | 换简短 keyword 重试 |
| `未找到相关经验帖` | 查询过窄 | 放宽学历词或公司词 |
