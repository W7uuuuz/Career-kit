# 零等待演示：一份真实的职业地图

这个目录是 **Career Kit 的真实产出**——一份样例简历经完整链路（差距分析 → 路线图 →
分阶段任务 → 打卡）生成的交付物。**无需安装任何东西**，双击 `career-map.html` 即可在
浏览器打开并交互（勾选任务、进度实时更新、本地持久化）。

- `career-map.html` — 交互式职业地图（`export_dashboard(mode="roadmap")`）
- `dashboard.html` — 进度仪表盘（`export_dashboard(mode="progress")`）
- `career-map.png` / `dashboard.png` — 截图，供 README 使用
- `demo_profile.json` — 生成的完整档案（含 `plan` / `tasks` / `checkins`）

## 首屏诊断（教练在出 HTML 前就给结论）

> 你不是零基础——你能独立搭起完整的 Agent 链路（6 个 LangGraph Subgraph + 双提供商网关 +
> 3 层 RAG）。但你的简历有一个**致命盲区**：全是独立开发，**零团队协作证据**，而大厂校招最看
> 这个。方向对，你缺的不是技术，是「被协作过」的证明。

这条结论不是话术，而是锚定在三条证据上：简历的「独立开发」经历、真实 JD 的协作要求、
以及 `start_level` 打分明细（教育/实习/协作/技能/项目）。

## 这份地图演示了什么

1. **起点判定而非直觉**：`start_level = 小厂`，逐维度打分得出，不是拍脑袋。
2. **负面信号审计**：识别出「小公司 + 独立开发 + 实习仅 3 个月」三处雷点，各配叙事弱化 + 补证据动作。
3. **层级连续的过渡规划**：起点小厂 → 先补协作证据（开源贡献）→ 中厂实习过渡 → 冲大厂校招，
   不是一步跳级。
4. **jd 三件套**：中厂阶段有真实抓取的 JD 依据；大厂阶段如实标为「待导入真实 JD」占位，
   绝不编造要求。
5. **可打卡的执行颗粒**：按比例任务（进度滑条）、按天任务（今天打卡），完成即沉淀能力证据。
