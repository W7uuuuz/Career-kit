# 快速行业扫描（扫盲子流程）

目标：3-5 分钟建立行业地图，不替代规划。

## 输入

必填：

- 行业：默认互联网/软件行业（`industry="internet"`）

可选：

- 专业：只用于个性化，不是入口
- 学校、学历、届别：当前只记录，不做同校过滤
- 城市：用于招聘样本
- 样本上限：默认 12

## 调用

调用一次：

```text
get_industry_snapshot(
  industry="internet",
  major="...",
  school="...",
  degree="...",
  graduation_year="...",
  city="...",
  limit=12
)
```

不要串多个抓取工具；不要在这一步调用 `gather_research_data`。

## 输出结构

只讲四段，控制在一屏：

1. **行业地图**：3-6 个子方向，一句话说明。
2. **岗位卡**：从返回的 `roles` 里选 3-5 个，讲工作内容、门槛、技能、成长。
3. **市场与薪资**：只引用返回的 `market` / `benchmarks`；标注来源、样本数、口径。
4. **你的位置与下一步**：如果填了专业，讲专业匹配；最后问想深入哪个方向。

## 数据纪律

- 没有 `market.salary.count`：说「本次未获取薪资样本」，不要补数字。
- BOSS 未登录：说「本次未获取实时招聘薪资」，不要把它说成行业没薪资。
- 来源是招聘样本：明确说「招聘区间，不是毕业生实际薪资」。
- 来源是麦可思：明确说「全国本科整体参考，不是本行业单独统计」。
- 没有同专业去向：说「尚未接入」，不要用 LLM 记忆补。

## 结束

```text
看完这些，有没有哪个方向想进一步了解？
```

有方向就进入目标选择；没有就换方向或先聊兴趣。
