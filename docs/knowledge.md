# 知识库

> Career Kit 本地知识库结构说明

## 位置

知识库属于**用户自有数据**，存放在用户主目录：

```
~/.career-kit/knowledge/
├── resumes/       # 参考简历
├── jds/           # 收集的 JD（含 scraper 自动写入）
├── interviews/    # 面经（含 scraper 自动写入）
└── market/        # 市场数据
```

路径常量统一定义在 `src/paths.py`；仓库内的 `data/knowledge/` 已停用，仅作测试样例存放点。

## 目录说明

### resumes/ - 参考简历

存放同背景前辈的简历、简历模板。

**示例文件**：
- `双非前端转AI.md` - 同背景前辈的简历参考
- `211后端字节.md` - 目标公司前辈的简历

### jds/ - 收集的 JD

存放目标岗位的职位描述。

**示例文件**：
- `字节_Agent开发.md` - 目标岗位 JD
- `携程_实习.md` - 实习岗位 JD

### interviews/ - 面经

存放面试经验、面试题。

**示例文件**：
- `字节_Agent_一面.md` - 面试经验
- `Agent开发_高频题.md` - 整理的高频面试题

### market/ - 市场数据

存放行业趋势、薪资数据、技能图谱。

**示例文件**：
- `AI岗薪资2025.md` - 薪资数据
- `Agent技能图谱.md` - 技能要求总结

## 支持的文件格式

- `.md` - Markdown 文本
- `.txt` - 纯文本
- `.json` - JSON 数据

## 使用方式

1. 将收集的资料放入对应目录
2. 需要时调用 `search_knowledge` 检索；不会自动后台扫描
3. 文件名建议包含关键词（如 `字节_Agent开发_面经.md`），便于匹配

## 与企业数据源的关系

- **企业数据源**（`src/scrapers/`）：实时抓取的企业数据，抓取后自动写入知识库
- **知识库**（`~/.career-kit/knowledge/`）：历史积累 + 用户手动放入的资料

两者互补：知识库用于查历史资料，企业数据源用于获取最新岗位；由 LLM 按需组合。
